# Data Source Definition

### Entities

Taken from GeoTIR research, filtered to Japan only. Each row is a unique landmark identity. The primary key is `wikimedia_url` (the Wikimedia page URL of the landmark), but an `entity_id` column was added to make it easier to reference in code. All attributes came directly from the Wikimedia page. The `category` column is the exception — it was generated by mapping the `instance` tag attribute to 5 predefined categories (taxonomy from GeoTIR) using `src/wiki_category.py`.

### Landmark

Also taken from GeoTIR, filtered to Japan only. Each row is a single landmark record (image + metadata). Two category columns to be aware of:

- `pred_label`: the original category from GeoTIR. Generated by a vision model (InternVL2.5 3B — need to confirm by reading the GeoTIR paper).
- `category`: newly added column, joined from the entities data. This is the heuristic category based on instance tag mapping, as described above.
